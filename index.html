⬆ Летадло · концепт

Автоматический набор безопасной высоты при потере радиосвязи.

Потеря-link→ Набор до целевой высоты→ Удержание / поиск связи→ Возврат (RTH)
Это макет будущей вкладки. Чтобы функция работала по-настоящему, нужна поддержка в прошивке iNav и своя MSP-команда для записи параметров. Сайт сам по себе не может научить полетник новому поведению.

Проектируемые параметры: целевая высота (м), максимальный тангаж (°), таймаут ожидания связи, поведение при недоборе высоты.
